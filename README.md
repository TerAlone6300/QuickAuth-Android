# QuickAuth-Android (Kotlin)

QuickAuth-Android is a native Android application built with Kotlin and Jetpack Compose, designed to act as a client for the [QuickAuth](https://github.com/TerAlone6300/QuickAuth) system.

## Overview

This application enables secure management and generation of Time-based One-Time Passwords (TOTP) directly on your Android device. It synchronizes your account list and authentication secrets with a central QuickAuth server while maintaining local control.

## Key Features

- **Secure TOTP Generation:** Native Kotlin implementation for generating TOTP codes.
- **Synchronized Accounts:** Securely syncs your accounts with the QuickAuth server using Retrofit.
- **Modern UI:** Built with **Jetpack Compose** and **Material 3**, featuring support for both Light and Dark themes.
- **Secure Storage:** Uses Android **EncryptedSharedPreferences** for local data encryption (accounts, sync tokens and the sync encryption key).
- **End-to-end encrypted sync:** secrets are encrypted on the device before upload; the server never sees them (see below).
- **CI/CD Integration:** Automatically builds and signs release APKs using GitHub Actions.

## Requirements

- Android SDK 34 (API 34)
- Java 17 (Eclipse Temurin)

## Sync security (v1.2.0)

TOTP secrets are encrypted **on the device** with a key derived from a separate *sync passphrase* (PBKDF2-HMAC-SHA256, 600,000 iterations; HMAC-SHA256 keystream plus an HMAC-SHA256 tag). The server only stores opaque blobs under blinded ids, so it can read neither your secrets nor your account names, and it cannot forge entries (it can still delete or roll back individual entries).

- Choose the passphrase on your first device and enter the **same** one on every other device (Android app, Python client >= 1.9.1). It must differ from your login password, because the server sees the login password. If you forget it, synced data cannot be recovered.
- Prefer an ASCII passphrase: keyboards on different platforms can normalise accented characters differently.
- The first sync after upgrading re-uploads your accounts encrypted and deletes the old plain-text copies from the server. Upgrade **all** devices: an older client keeps uploading plain text (newer clients ignore and delete those entries). Consider rotating TOTP secrets that were ever synced in plain text.
- Requires a QuickAuth server >= 1.9.1.
- Access/refresh tokens and the encryption key are kept in `EncryptedSharedPreferences`; clear-text HTTP is disabled, so use an `https://` server URL.
- The biometric lock is on by default only if the device has a fingerprint/face enrolled. Without one it stays off (it can't be switched on until one is enrolled), and if the biometrics are removed later the lock turns itself off instead of closing the app.
- `app/src/test/.../E2eeTest.kt` pins test vectors generated by the Python client; keep it green so both clients stay interoperable.
